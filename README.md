## About

I am an Information Systems student also pursuing a degree in Systems Analysis and Development, with independent studies in computer science and software engineering.

My interests are centered on understanding software close to the machine: C programming, Linux, computer architecture, operating systems, debugging and the engineering practices behind reliable tools.

I value clear documentation, deliberate experimentation and learning by building.

- Data structures, algorithms and software design
