## About

I am an Information Systems student also pursuing a degree in Systems Analysis and Development, with independent studies in computer science and software engineering.

My interests are centered on understanding software close to the machine: C programming, Linux, computer architecture, operating systems, debugging, networking and the engineering practices behind reliable tools.

I value clear documentation, deliberate experimentation, reproducible tests and learning by building.

## Independent Computer Science Study

Alongside formal education, I maintain an independent Computer Science study path focused on fundamentals and implementation: logic and mathematics, algorithms and data structures, C programming, computer architecture, operating systems, networks, web technologies and cybersecurity.

The goal is to understand systems from first principles, validate concepts through practical experiments, and document the results in public projects.

## Current focus

- Systems programming in C and Linux
- Computer architecture, memory, processes and operating-system fundamentals
- Data structures, algorithms and software design
- Networking, web security and defensive security labs
- Testing, debugging, static analysis and maintainable open-source projects
